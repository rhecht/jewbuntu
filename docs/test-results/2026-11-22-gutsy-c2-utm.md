# Jewbuntu Classic 7.10 c2: live CD and hard-disk install in UTM (2026-11-21/22)

VM: UTM 5.0.8 on the M1 iMac, QEMU i386 emulation, 4 GB RAM, 8.6 GB virtual IDE disk, user-mode
networking. Screenshots through a VNC port added to the VM (`-vnc`), keys through the QEMU
monitor; in `2026-11-22-gutsy-c2/` (website-quality shots in `website/`).

Final ISO: `jewbuntu-classic-7.10-c2-32bit.iso`, 714,696,704 bytes (fits a 700 MB CD-R), sha256
`842d5638f192f87a893e49129bfba9449d5f3269e9cfe838615fab9ec1b9f9ef`, with
jewbuntu-shulgo-gtk2 `0.1.1~git202611220359.74f1dfd`. Earlier c2 builds (eb80e85e, ecfb7840,
6fd7e09f) were test builds and are not kept.
