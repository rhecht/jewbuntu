# Jewbuntu Classic 7.10 c2: live CD and hard-disk install in UTM (2026-11-21/22)

VM: UTM 5.0.8 on the M1 iMac, QEMU i386 emulation, 4 GB RAM, 8.6 GB virtual IDE disk, user-mode
networking. Screenshots through a VNC port added to the VM (`-vnc`), keys through the QEMU
monitor; in `2026-11-22-gutsy-c2/` (website-quality shots in `website/`).

Released ISO: `jewbuntu-classic-7.10-c2-32bit.iso`, 728,774,656 bytes (fits a 700 MB CD-R), sha256
`2130b99387a7fc4911c9f24deadace10aa49ae97296c11cdee0d38fbfbb619fb`, with jewbuntu-firefox
`3.6.28-0jewbuntu1`, the TLS bridge in jewbuntu-web-tools, and jewbuntu-shulgo-gtk2
`0.1.1~git202611220659.10e9bfe`. The install rows below used build 842d5638 (same installer
changes, Firefox 2, ShulGo 74f1dfd); earlier builds were test builds and are not kept.
