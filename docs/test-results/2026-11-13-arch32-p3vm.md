## Found and fixed

- Top-bar status icons (lock, switch user, suspend, shut down, log out, and the tray area) were
  invisible: the Jewbuntu icon theme draws them #f2f2f2 for GNOME's dark bar, on Xfce's #f1f1f1
  bar. Switched the Xfce and greeter defaults to the Jewbuntu-light variant (#363636 status
  icons); confirmed live in this VM (screenshot -desktop.png). The rebuilt package was not yet
  reinstalled in the VM (Docker stays off while the VM runs).
