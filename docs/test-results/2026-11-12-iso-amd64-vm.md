# Jewbuntu ISO install test: amd64, emulated VM (2026-11-12)

**Image:** `jewbuntu-0.1.0-m1.26-amd64.iso`, SHA-256
`4edd8fbec49f07c2e467e3cb94f7490ba16d91c5a7a7e5571955c584c2630033`, built by `ci/build-iso.sh`
from `ubuntu-26.04.1-desktop-amd64.iso` (SHA-256 verified against Ubuntu's SHA256SUMS).

**VM:** UTM on an Apple M1 iMac, QEMU x86_64 TCG emulation (multi-threaded), q35, UEFI, 4 vCPUs,
6 GB memory, 30 GB virtual IDE disk, virtio-vga, shared network (online). The owner clicked
through the installer.

## Result

| Step | Result |
|---|---|
| Boot from ISO (UEFI) | OK, Ubuntu's boot menu, then the live session |
| Installer screens | All interactive (language, keyboard, network, apps: Default selection, third-party software off, disk: erase, identity); no autoinstall prompt |
| Copying files | OK (about 8.2 GB written) |
| Postinstall | Users and language packs OK; unattended-upgrades installed security updates (about 1.5 h emulated), `finish: cmd-in-target: SUCCESS` |
| Late command (Jewbuntu) | Ran; the installer reached "Restart Now" (it stops with an error if a late command fails) |
| Restart | Live session spewed SQUASHFS/sr0 errors after ejecting the virtual disc and could not run its shutdown binary (known live-session behaviour); forced restart from UTM |
| First boot from disk | OK. Plymouth crashed once (Ubuntu's splash; Jewbuntu ships no Plymouth theme) and the boot continued |
| Login screen | Jewbuntu GDM: Star of David, Jewbuntu logo |
| Desktop | Jewbuntu wallpaper (light), Jewbuntu dock |
| First-login look prompt | Appeared; "Apply Jewbuntu look" gave the glass dock, top bar and theme (confirmed by the owner, 16:3x) |

## Not checked

- `/var/log/jewbuntu-install.log` and `dpkg -l 'jewbuntu-*'` in the VM. The login screen, wallpaper,
  dock and look prompt come from jewbuntu-gnome, -branding, -desktop and the skin, so those were
  installed.
- The VM was deleted afterwards at the owner's request.
- Real hardware and Secure Boot.

## Timings (emulated; real hardware is far faster)

- Boot to installer: about 10 min.
- Copy: about 50 min.
- Security updates: about 1.5 h.
- First boot to desktop: about 10 min.
