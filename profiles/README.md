# Installation profiles

| Profile | Packages | Notes |
| --- | --- | --- |
| Desktop | `jewbuntu-desktop` (pulls core, branding, hebrew, Ubuntu desktop) + upgrade-tools | Primary |
| Node | `jewbuntu-node` (M4): core, doctor, upgrade-tools, optional AI. No graphical session, so silent. | On Ubuntu Server |
| Lite | Documented extension point only: Xfce session sharing the same services | Only if measurements justify it |
| Developer Pack | `jewbuntu-dev` (M4) | Optional |
| AI Pack | `jewbuntu-ai` (M4) | Optional, never required by desktop |
